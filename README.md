# 🎮 GameSpace

**GameSpace** — это современный сайт-визитка о мире игр.
Проект создан в рамках обучения Frontend-разработке и показывает, как с помощью **HTML, CSS и JavaScript** можно создать красивый и интерактивный веб-сайт.

## 📌 О проекте

Сайт предназначен для людей, которые любят компьютерные и видеоигры. На нём можно узнать о представленных игровых услугах и посмотреть тематические изображения.

Главная идея проекта — сделать простой, красивый и удобный сайт в игровой атмосфере.

## ✨ Возможности

* 🎮 Главная страница с информацией о проекте
* 🕹️ 4 игровых направления/услуги
* 🖼️ Изображения, связанные с играми
* 🌞 Переключатель **День / Ночь**
* 🎨 Современный дизайн
* 🔤 Подключённый дополнительный шрифт
* 📱 Адаптация под разные размеры экрана
* ⚡ Интерактивные элементы с помощью JavaScript

## 🎨 Дизайн

В проекте используется мягкая природная цветовая палитра:

* `#8B9474`
* `#6CAE75`
* `#8BBD8B`
* `#C1CC99`
* `#F5A65B`

Эти цвета используются для фона, кнопок, текста и декоративных элементов.

## 🛠️ Использованные технологии

* **HTML5** — структура сайта
* **CSS3** — оформление и адаптивный дизайн
* **JavaScript** — интерактивность и переключение режима День/Ночь

## 📂 Структура проекта

```text
GameSpace/
│
├── index.html
├── styles.css
├── script.js
└── README.md
```

### `index.html`

Основная структура сайта: заголовки, текст, кнопки, изображения и блоки с информацией.

### `styles.css`

Отвечает за внешний вид сайта: цвета, шрифты, расположение элементов, размеры и анимации.

### `script.js`

Отвечает за интерактивные элементы сайта, в том числе переключатель между дневным и ночным режимами.

## 🚀 Как запустить проект

1. Скачайте или склонируйте репозиторий.
2. Откройте папку проекта.
3. Найдите файл `index.html`.
4. Откройте его в браузере.
5. Сайт готов к использованию 🎮
